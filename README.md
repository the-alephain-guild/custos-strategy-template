# custos-strategy-template

A starting point for a repository of trading strategies that run on
[Custos](https://github.com/the-alephain-guild/custos), the self-hosted strategy
runner.

This repository is under construction. The layout, tooling and documentation
arrive in the commits that follow; until then there is nothing to run.
